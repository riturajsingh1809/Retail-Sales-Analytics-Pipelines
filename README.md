# 📊 Retail Sales Analytics Pipeline

An end-to-end *Retail Sales Analytics* project focused on transforming raw sales data into meaningful business insights through data cleaning, Python analysis, and Tableau visualization.

## 🎯 Project Overview

The objective of this project is to analyze retail sales data and understand important business metrics such as sales performance, profit, orders, quantity, product performance, category performance, regional performance, payment methods, and monthly sales trends.

The project follows a structured analytical workflow from *data preparation to business insights and dashboard visualization*.

## 🛠️ Tools & Technologies

* *Microsoft Excel* – Data cleaning and preparation
* *Python* – Data analysis and KPI calculation
* *Pandas & NumPy* – Data processing and analysis
* *Tableau* – Interactive dashboard and data visualization
* *GitHub* – Project documentation 

## 🧹 Data Cleaning

The raw retail sales dataset was cleaned and prepared using *Microsoft Excel*.

The major cleaning activities included:

* Checking missing values
* Identifying duplicate records
* Checking data types and formats
* Standardizing text values
* Validating numerical fields
* Checking date consistency
* Preparing the cleaned dataset for analysis

The cleaned dataset was then used for further analytical processing.

## 📈 Python Analysis

Python was used to perform analytical calculations and generate structured outputs.

Key analysis included:

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Average Sales
* Average Profit
* Category-wise Sales & Profit
* Region-wise Sales & Profit
* Product-wise Sales & Profit
* Payment Mode Analysis
* Monthly Sales Analysis
* Overall Profit Margin
* Highest Sales Category
* Highest Sales Region
* Best-Selling Product

## 📊 Tableau Dashboard

An interactive Tableau dashboard was created to present the analytical results in a simple and business-friendly format.

### Dashboard Components

* *Total Sales KPI*
* *Total Profit KPI*
* *Total Orders KPI*
* *Total Quantity KPI*
* *Sales by Category*
* *Sales by Region*
* *Monthly Sales Trend*
* *Product-wise Sales*

The dashboard helps users quickly understand overall performance and identify important sales trends and high-performing business segments.
